# note-card-ui
노트 카드 형태의 간단한 UI Form

# 컨셉? 기획

## 1. 개요
  * 노트패드의 직관적이고 심플한 디자인을 웹 UI에 적용하여 사용자가 쉽게 메모하고 관리할 수 있도록 제공하는 것

## 2. 주요 기능
  * 구현 중
     * 페이지(탭?) 기능
  * 구현 
     * 텍스트 입력 및 편집: 노트패드처럼 간단한 텍스트 입력과 편집 기능 제공 (완료: [2109ac6](https://github.com/kimminhyug/note-card-ui/commit/2109ac699435078a23dc7ea8a7800fb07c32c235))
   * 개발 어느 정도 되면 아래 기능 필요할지는 검토 필요
     * 팬 기능도 있어야하나
     * 자동 저장: 사용자가 입력한 내용을 자동으로 저장하는 기능
     * 다크 모드등 테마 기능
     * JSON IMPORT? EXPORT? | 로컬스토리지?
       * 노트 공유 기능
       * 버전 관리

## 3. UI 컴포넌트 요소
  * 노트 제목
    * Optional
  * 설정창
    * 노트에 대한 스타일 설정
      * 폰트 크기 / 줄 간격
      * 폰트 앞 여백?     
  * 탭(사이드 우측바)
    * 생성된 노트 선택 버튼
    * 새 노트 추가 버튼
  * 메인 콘텐츠 영역
    * 줄 간격을 이용하여 가로 줄무늬 출력
      * 간격은 폰트 크기와 동일하게 설정 
    * 텍스트 만을 제공할지는 검토 필요
    * 텍스트 영역(현재는 span만 되어있으나 컴포넌트 화 필요. note-row.tsx?)
      * 줄무늬 가운데쯤 텍스트가 생성되도록 padding 지정
      * 드래그 하여 줄을 바꿀 수 있는 기능?
  * 하단 메뉴
    * 저장 기능 

## 4. 디자인 컨셉?
  * 한줄: 회의할떄 사용하는 노트에 포스트잇이 붙은 느낌
  * 색상
    *  정돈된모던하면서도 다채로운 공책 스타일 노트(색상은 파스텔 색? 좀 연하고 번지는 느낌으로 바꿔야함)
  * 폰트
    *  손글씨 스타일 폰트(중요 찾아야 함)
  * 아이콘
    * 저장, 공유 아이콘(아이콘도 폰트 적용 되는 아이콘으로)
  * 애니메이션
    *  페이지를 넘기는듯한 느낌의 애니메이션

## 5. 기술 스택
  * 프론트엔드
    *  Next.js(제거) React, css
